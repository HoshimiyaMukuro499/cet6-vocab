# 单词本

在 Windows 上用 Word 维护单词本，手机浏览器随时看最新版。

**网站地址**：`https://______________.pages.dev` ← 部署后把地址填到这里

---

## 日常怎么用

只有两个操作，都在这个文件夹里：

| 想做什么 | 双击 |
|---|---|
| 编辑单词本 | `编辑文档.bat` |
| 改完了，发布到手机 | `推送更新.bat` |

`推送更新.bat` 会自动做三件事：用 Word 把文档导出成 PDF → 提交改动 → 推送到 GitHub。
推送成功后约 30 秒，手机上刷新就是最新版。

**手机上**：浏览器打开上面的网址，建议「添加到主屏幕」，之后像 App 一样一点即开。
顶部有「下载 PDF」和「下载 Word」两个按钮，下载到本地后断网也能看。

```
tools\
  export-pdf.ps1      ← 调用 Word 导出 PDF 的脚本
编辑文档.bat
推送更新.bat
```

## 出问题怎么办

**PDF 导出失败，但 Word 文档推送成功了？**
最常见的原因是 Word 里开着弹窗对话框（比如"是否保存"），自动化调用会卡在上面。
把 Word 里的对话框点掉，再双击一次 `推送更新.bat`。

**连点两次推送，第二次报"无法启动 Word"？**
Word 关闭是异步的，进程要十几秒才真正退出。脚本已内置重试，等十几秒再试即可。

**手机上打不开网址？**
`pages.dev` 在中国大陆没有节点，走跨境线路，部分运营商（尤其移动）可能连不上。
先试试换 WiFi / 换流量。如果长期不行，见下面「换域名」。

**手机上还是旧内容？**
先下拉刷新。页面已设置不使用缓存，正常情况下刷新即可拿到最新版。

## 换域名（如果 pages.dev 长期打不开）

`pages.dev` 的失效主要是**域名级封锁**，换成自己的域名可以绕开。
花 ¥10–30/年 买个 `.top`/`.xyz`，在 Cloudflare Pages 项目里
`Custom domains` → 添加域名，按提示改 DNS 即可。需要实名，但**不需要备案**。

注意：跨境线路的延迟（约 150–300ms）换域名也解决不了，只能缓解"打不开"。

网上流传的 Cloudflare「优选 IP」不要用——违反服务条款，可能直接封号。

## Cloudflare Pages 配置备忘

如果哪天需要重建项目，构建设置是：

- Framework preset: `None`
- Build command: **留空**
- Build output directory: `public`

不需要任何构建步骤：`推送更新.bat` 已经在本地把一切准备好，
Cloudflare 只负责把这些静态文件发出去。
